# HCI Seat Selection Prototype

Medium-fidelity React prototype for preference-guided concert seat selection,
visual verification, exact-seat selection, and optional advance preparation.

## Run locally

```bash
npm install
npm run dev
```

## Planned flow

1. Enter ticket and seat preferences.
2. Review ranked valid seat-group recommendations.
3. Verify a recommendation on the venue map and inspect the expected view.
4. Select an adjacent seat group with early constraint feedback.
5. Review and confirm the selection.

The saved-draft feature should remain an optional way to pre-populate the
preference screen before a time-sensitive ticket sale.
